# チラシ伝わり度セルフチェック

Canvaなどで作ったチラシを配る前に、**伝わりやすさ**をかんたんに確認できる静的Webページです。  
HTML/CSS/JavaScriptのみで動き、診断結果はブラウザ内だけで表示されます。

## 特徴

- 完全な静的サイト（GitHub Pagesで公開可能）
- 画像アップロード・ログイン・個人情報入力なし
- APIや外部ライブラリ不使用
- チェック数に応じた点数表示
- 3段階の診断コメント
- 未チェック項目に応じた改善ヒント表示
- リセットボタンあり
- スマホファーストのやさしいUI

## ファイル構成

- `index.html` : ページ本体
- `style.css` : 見た目（スマホファースト）
- `script.js` : チェック項目描画、採点、結果表示、リセット処理
- `README.md` : この説明

## 使い方

1. `index.html` をブラウザで開く
2. チラシを見ながらチェック項目にチェック
3. 「結果を見る」を押して点数とアドバイスを確認
4. 「リセット」で最初からやり直し

## GitHub Pagesで公開する手順（初心者向け）

1. この4ファイルをGitHubリポジトリのルートに置く
2. GitHubでリポジトリの **Settings** を開く
3. 左メニューの **Pages** を選ぶ
4. **Build and deployment** の Source を **Deploy from a branch** にする
5. Branch を `main`（または公開したいブランチ）/`root` にして保存
6. 数分待つと公開URLが表示される

## 注意

- このページは診断結果を保存しません。
- 入力した内容はサーバーに送信されません（通信なし）。
- 本診断はセルフチェック用の目安です。
